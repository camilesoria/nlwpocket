## 📋 Sobre o Projeto

O **Prompt Manager** é uma aplicação front-end desenvolvida para ajudar usuários a organizar e gerenciar seus prompts de Inteligência Artificial em um só lugar. Chega de perder aquele prompt genial em um bloco de notas perdido! Com essa ferramenta, é possível criar, salvar, editar, buscar e copiar seus prompts de forma rápida e intuitiva.

Este projeto foi construído do zero, aplicando conceitos essenciais de **HTML, CSS e JavaScript**, e utilizando o **GitHub Copilot** e o **Google Gemini** como uma ferramenta de produtividade para acelerar o desenvolvimento.

<br>

## ✨ Funcionalidades

-   ✅ **Criação e Edição de Prompts:** Interface para criar e editar títulos e conteúdos de prompts.
-   💾 **Persistência de Dados:** Os prompts são salvos localmente no navegador usando `localStorage`.
-   🗑️ **Gerenciamento Completo:** Funcionalidades para salvar, deletar e criar novos prompts.
-   📋 **Copiar com Um Clique:** Botão para copiar o conteúdo do prompt para a área de transferência.
-   🔍 **Busca em Tempo Real:** Filtre e encontre seus prompts pelo título instantaneamente.
-   📱 **Design Responsivo:** A interface se adapta a diferentes tamanhos de tela, de desktops a celulares.

## 🚀 Como Executar o Projeto

Este projeto é totalmente front-end, então é super simples de executar!

1.  **Clone o repositório:**
    ```bash
    git clone https://github.com/camilesoria/nlwpocket.git
    ```
2.  **Abra o arquivo `index.html`:**
    -   Navegue até a pasta do projeto e abra o arquivo `index.html` no seu navegador de preferência.
    -   Ou, se estiver usando o VS Code com a extensão "Live Server", clique com o botão direito no `index.html` e selecione "Open with Live Server".

## 🎓 Aprendizados

Durante o desenvolvimento deste projeto, pude praticar e aprofundar meus conhecimentos em:

-   **Estruturação Semântica com HTML:** Uso correto de tags como `<main>`, `<aside>`, `<header>`, etc.
-   **Estilização Avançada com CSS:** Conceitos de Flexbox para layout, uso de variáveis CSS para um tema consistente e Media Queries para responsividade.
-   **Manipulação do DOM com JavaScript:** Selecionar e alterar elementos da página de forma dinâmica.
-   **Eventos e Interatividade:** Capturar ações do usuário, como cliques e digitação, com `Event Listeners`.
-   **Persistência de Dados no Front-End:** Utilização do `localStorage` para salvar e carregar informações.
-   **Desenvolvimento Assistido por IA:** Como usar o GitHub Copilot de forma consciente para aumentar a produtividade sem perder o controle do código.
